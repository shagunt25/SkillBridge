python
from pydantic import BaseModel

Pydantic is FastAPI's data-validation library. BaseModel is the parent class you inherit from to define the "shape" of your data — what fields it has, what types they should be.

python
from typing import Optional

Optional comes from Python's built-in typing module. Optional[str] just means "either a str, or None." It's used to mark fields that don't have to be provided
